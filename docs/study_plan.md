# Пошаговый учебный план для 13-летнего

## Цели обучения
1. Понять, как устроены чат-боты и API.
2. Научиться писать простые программы на Python.
3. Собрать MVP-бота, который принимает запросы времени, проверяет лимиты и отправляет родителям уведомления.
4. Познакомиться с базой данных и деплоем (на базовом уровне).

## Формат
- Длительность: 8–10 недель.
- Режим: 3 занятия в неделю по 60–90 минут.
- Стиль: «вайбкодинг» — короткие упражнения + мини-проекты.

#### Занятие 2 — «Числа и расчеты»
**Цель:** научиться складывать, вычитать и работать с минутами.

**Шаги:**
1. Создать переменные и сложить минуты:
   ```python
   a = 30
   b = 45
   total = a + b
   print("Всего минут:", total)
   ```
2. Перевести минуты в часы:
   ```python
   hours = total // 60
   minutes = total % 60
   print("Это", hours, "часов и", minutes, "минут")
   ```
3. Ввод чисел от пользователя:
   ```python
   a = int(input("Сколько минут? "))
   b = int(input("Сколько еще минут? "))
   print("Всего:", a + b)
   ```

**Мини-челлендж:** программа считает, сколько минут осталось до лимита 180.

**Что получилось:** программа умеет считать и превращать минуты в часы.

#### Занятие 3 — «Условия и логика»
**Цель:** научиться, чтобы программа “решала”, что отвечать.

**Шаги:**
1. Простой пример `if`:
   ```python
   minutes = int(input("Сколько минут ты уже использовал? "))
   if minutes < 180:
       print("Можно еще!")
   else:
       print("Лимит исчерпан.")
   ```
2. Добавить проверку на количество запросов:
   ```python
   requests = int(input("Сколько было запросов сегодня? "))
   if requests < 5 and minutes < 180:
       print("Запрос можно принять.")
   else:
       print("Запрос отклонен.")
   ```

**Мини-челлендж:** добавить сообщение «Осталось X минут».

**Что получилось:** программа умеет принимать решения.

### Неделя 2 подробно: 3 занятия по 60–90 минут
> Функции — это как «заклинания» в игре: один раз написал — и можно вызывать сколько угодно.

#### Занятие 1 — «Зачем нужны функции»
**Цель:** понять, как упрощать код и не повторяться.

**Шаги:**
1. Посмотреть пример без функции:
   ```python
   minutes = 135
   hours = minutes // 60
   rest = minutes % 60
   print(hours, "ч", rest, "мин")
   ```
2. Сделать то же самое через функцию:
   ```python
   def minutes_to_hours(minutes):
       hours = minutes // 60
       rest = minutes % 60
       return hours, rest

   h, m = minutes_to_hours(135)
   print(h, "ч", m, "мин")
   ```

**Мини-челлендж:** вызвать `minutes_to_hours` для 30, 90 и 180 минут.

**Что получилось:** функция упрощает повторяющиеся расчеты.

---

#### Занятие 2 — «Функции с условиями»
**Цель:** научиться возвращать ответ «да/нет» для логики бота.

**Шаги:**
1. Создать функцию проверки лимита:
   ```python
   def can_request_more(used_minutes, used_requests):
       if used_requests >= 5:
           return False
       if used_minutes >= 180:
           return False
       return True
   ```
2. Проверить разные случаи:
   ```python
   print(can_request_more(100, 2))  # True
   print(can_request_more(190, 2))  # False
   print(can_request_more(100, 5))  # False
   ```

**Мини-челлендж:** сделать функцию, которая считает, сколько минут осталось.

**Что получилось:** функция может принимать решение.

---

#### Занятие 3 — «Собираем мини-программу»
**Цель:** связать несколько функций в одну маленькую программу.

**Шаги:**
1. Написать функцию, которая спрашивает у пользователя, сколько минут он уже использовал.
2. Вызвать `can_request_more` и вывести результат:
   ```python
   used_minutes = int(input("Сколько минут использовано сегодня? "))
   used_requests = int(input("Сколько запросов было сегодня? "))

   if can_request_more(used_minutes, used_requests):
       print("Запрос можно принять.")
   else:
       print("Лимит исчерпан.")
   ```

**Мини-челлендж:** если лимит не исчерпан, попросить, сколько минут хочет ребенок, и показать итог.

**Что получилось:** мини-программа, похожая на логику будущего бота.
